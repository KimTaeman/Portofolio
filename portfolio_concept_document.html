The Journey to the Summit

A Narrative 3D Portfolio Concept

Core Concept

This portfolio is a scrollytelling experience. The user's scroll controls the flow of time, moving a 3D character along a continuous path that represents your personal and professional journey.

Aesthetic: "Soft 3D" or "Stylized Clay." Characterized by warm pastel colors, matte surfaces, simple geometric shapes, and soft, diffuse lighting (no harsh shadows).

Key Metaphor: Life as a climb. Starting from playful curiosity (playground), moving through learning (campus path), overcoming challenges (mountain climb), and reaching a confident future (summit).

0% - 20% Scroll

Scene 1: The Playground (Introduction)

The World

A stylized, "soft 3D" playground. The look is matte, clean, and warm, like your reference images. Features a simple orange slide, soft green "gumdrop" trees, and a cream-colored ground.

Character & Action

  • Start (0%): Character is a stylized "chibi" figure in a school uniform, sitting at the top of the slide, waving.
  • Action (0-10%): On scroll, the character stops waving and slides down. The camera performs a dynamic swoop to follow.
  • Landing (10-20%): Character lands with a playful hop and begins a walking loop toward the path.

Key Interaction: The "Growth" Morph

As the character walks behind a large tree or playground structure, the model instantly swaps from School Uniform to University Uniform.

Copy (HTML Overlay)

"Hi, I'm [Your Name]! Welcome to my world. I'm a developer who believes every great project starts with curiosity."

20% - 50% Scroll

Scene 2: The Campus Path (Skills & Hobbies)

The World

A University Campus Path lined with "soft 3D" cherry blossom trees (simple trunks, pink cloud-like petals). Gentle falling petal particles fill the air.

Character & Action

Character is in a university uniform, walking or lightly jogging along the path with a focused, steady pace. Camera follows in a smooth tracking shot.

Interactions

  • Hobbies (Fun): Interactive 3D items along the path (Easel, Badminton Racket). Clicking them opens small 2D cards with personal details.
  • Skills (Technical): A laptop on a bench. Clicking it opens a clean 2D modal listing technical skills (Languages, Frameworks, Databases).

Copy (HTML Overlay)

"I spent my time learning, growing, and building my foundation."

50% - 70% Scroll

Scene 3: The Mountain Base (Experience)

The World & Character

  • World: Base of a stylized, low-poly mountain with a steeper "zigzag" trail.
  • Morph 2: Model swaps from University Uniform to Hiker/Explorer Outfit behind a large boulder.
  • Camera: Shifts to follow behind the character and tilts up, emphasizing the height of the mountain.

Key Interaction: The Retro Camera

At a scenic overlook (~60% scroll), the scroll pauses.

  • Character pulls out a 3D retro camera.
  • Camera "flashes," and 2D Polaroid images (your previous projects/experience) fly out.
  • User clicks Polaroids to read details. Closing them "unlocks" the scroll.

Copy (HTML Overlay)

"I put my skills to the test. Here's what I've built and where I've been."

70% - 100% Scroll

Scene 4: The Summit (Future & Contact)

The World

A flat, open summit with a stunning view. A vast skybox shows clouds below the peak and distant, glowing lights.

Camera Payoff (The Reveal)

As the character reaches the peak (90%), the camera soars up and over them, revealing the breathtaking view in a wide, cinematic shot. Character stands confidently, hands on hips.

Interactions

  • Day/Night Toggle: A ☀️/🌙 icon swaps the lighting. Night mode features a starry sky and glowing city lights below.
  • Telescope (CTA): A 3D telescope at the edge. Clicking it opens the final 2D "Contact Me" form.

Copy (HTML Overlay)

"Ready to explore the next peak. Let's build something amazing together."

Next Steps: Full Project Checklist

Use this detailed checklist to track your progress from concept to deployment.

Phase 1: Pre-Production & Design

Create Moodboard

Collect all reference images (David portfolio, soft clay examples) in Figma/Pinterest to lock in the aesthetic.

Define Color Palette

Select 4-5 hex codes for your world: Warm Cream (ground), Soft Orange (slide/accents), Calm Blue (sky/uniform), Cherry Pink (blossoms), Pine Green (trees).

Storyboard Scenes

Sketch rough "wireframes" of the 4 main camera angles (Slide view, Path tracking shot, Mountain low-angle, Summit wide shot).

Design 2D UI Elements

Mockup the HTML overlays: the "Hobby" cards, the "Skills" laptop screen, the "Polaroid" project gallery layout, and the final Contact form.

Phase 2: 3D Asset Creation

Model Characters & Animations

Create or source the 3 character variations (School, Uni, Hiker). Animate them (Wave, Slide, Walk, Jog, Hike, confident Idle).

Model World Scenes

Build the 3 main environments in Spline/Blender: Playground (with slide), Campus Path (cherry trees), Mountain (zigzag path & summit).

Model Interaction Props

Create the small clickable items: Easel, Badminton Racket, Laptop, Retro Camera, Telescope.

Export & Optimize

Export all models as .gltf or .glb. Use a tool like glTF-Pipeline or Squoosh to compress textures.

Phase 3: Technical Setup

Initialize Git Repo

Set up a new GitHub repository for version control.

Scaffold Vite Project

Run npm create vite@latest my-portfolio -- --template react to get a fast React setup.

Install R3F Dependencies

Install @react-three/fiber, @react-three/drei, and react-spring (or framer-motion-3d).

Set Up Project Structure

Create folders for /components/Scenes, /components/UI, and /models.

Phase 4: Development

Scene 1: The Slide

Implement the main <Canvas> and <ScrollControls>. Connect scroll offset to the slide animation. Add the "Hi, I'm..." HTML overlay.

Scene 2: Path & Hobbies

Animate the camera along the path. Implement the "Outfit Morph" (swapping models behind a tree). Add clickable Hobby items that open 2D cards.

Scene 3: Retro Camera Logic

Implement the scroll pause at the viewpoint. Build the complex interaction: Camera animation -> Flash -> 2D Polaroid Gallery reveal.

Scene 4: Summit & Polish

Animate the final "crane shot" camera reveal. Implement the Day/Night toggle (swapping HDRI environments). Connect the Telescope to the Contact Form.

Phase 5: Launch

Performance Optimization

Add <Suspense> and a loading screen. Verify smooth 60fps performance on average devices.

Mobile Responsiveness Check

Ensure 2D overlays work on small screens. Consider simplifying 3D effects for mobile if laggy.

Final Deployment

Deploy to Vercel/Netlify. Test live URL on multiple devices. Celebrate!
